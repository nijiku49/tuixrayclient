# Чек-лист ручной проверки harley

Автотесты покрывают парсинг, форматы подписок, заголовки, генерацию конфига
(его принимает настоящий `xray run -test`), пинг и подключение через локальный
xray-сервер, а режим TUN проверен в изолированных сетевых namespace.
Проверить руками осталось то, что зависит от реальных серверов, панелей и Alpine.

Отмечай `[x]`; если что-то не так — пришли вывод `harley logs -n 50` и
`harley status`.

## 0. Подготовка (Alpine)

- [ ] `apk add xray` — `xray version` показывает версию (желательно 26.x; для Hy2 и TUN нужна свежая)
- [ ] Скопировал `harley-linux-amd64` (или arm64) в `/usr/local/bin/harley`, `harley version` запускается без ошибок (бинарник статический)
- [ ] `modprobe tun`, `ls -l /dev/net/tun` — устройство есть

## 1. Первый запуск и вставка

- [ ] `harley` (обычный пользователь) — пустой экран с одной подсказкой «Вставь ссылку или ключ»
- [ ] Ctrl+Shift+V ссылки подписки — импорт начинается сразу, без Enter и без вопросов
- [ ] Появилась группа с именем из `profile-title` (кириллица/эмодзи из `base64:` отображаются правильно)
- [ ] У подписки показаны трафик «использовано / всего» и «до ДД.ММ.ГГГГ» — совпадают с панелью
- [ ] Если панель шлёт `announce` — видна строка «📢 …»
- [ ] Сразу после импорта у серверов крутится «…», затем появляются пинги в мс, harley подключился к самому быстрому (● у сервера и в статус-панели)
- [ ] Выключи «Автоподключение после импорта» (s → Enter) и вставь ключ — только импорт и пинг, без подключения

## 3. Пинг и список

- [ ] `p` — пинги обновляются; недоступный сервер показывает ✕
- [ ] Пинг правдоподобен (сравни с Happ на том же сервере — порядок величин совпадает)
- [ ] `f` — подключение к самому быстрому
- [ ] `/` + часть имени — фильтр; Esc — сброс
- [ ] `x` на сервере и на подписке — удаление с подтверждением
- [ ] Enter на заголовке подписки — свернуть/развернуть

## 4. Режим Proxy

- [ ] `curl -x socks5h://127.0.0.1:10808 https://ifconfig.me` — IP сервера
- [ ] `curl -x http://127.0.0.1:10809 https://ifconfig.me` — IP сервера
- [ ] Скорость ↑↓ и трафик в статус-панели растут при загрузке (например, `curl -x … -o /dev/null https://speed.hetzner.de/100MB.bin`)
- [ ] Время подключения тикает
- [ ] Смена портов в настройках (s) и переподключение — работает на новых портах
- [ ] Занятый порт (например, `nc -l -p 10808`) — понятная ошибка «порт … уже занят»

## 5. Режим TUN

- [ ] От обычного пользователя `m` → Enter — ошибка про root/CAP_NET_ADMIN, а не падение
- [ ] `rmmod tun` (если модуль) → подключение в TUN — подсказка `modprobe tun`
- [ ] `sudo harley`, `m` (TUN), Enter — `curl https://ifconfig.me` без прокси показывает IP сервера
- [ ] `ip route` — есть `0.0.0.0/1 dev harley0`, `128.0.0.0/1 dev harley0` и маршрут к DNS из `/etc/resolv.conf` через `harley0`
- [ ] DNS без утечек: https://browserleaks.com/dns или `dig +short whoami.akamai.net` — не видно DNS провайдера
- [ ] SSH-сессия к машине не обрывается при подключении (локальная сеть идёт напрямую)
- [ ] Доступ к роутеру (192.168.x.1) работает
- [ ] Если есть IPv6: `curl -6 https://ifconfig.co` — не утекает реальный IPv6 (либо идёт через VPN, либо ошибка)
- [ ] `d` — маршруты и интерфейс `harley0` исчезли, интернет работает как до подключения
- [ ] Hysteria2 в режиме TUN (UDP)

## 6. Маршрутизация

- [ ] Положил `geoip.dat`/`geosite.dat` в `/usr/share/xray/`
- [ ] `r` → «RU напрямую»: `curl https://yandex.ru/internet` (или 2ip.ru) — видно домашний IP; `curl https://ifconfig.me` — IP сервера
- [ ] Без geo-файлов «RU напрямую» — понятная ошибка, а не падение xray
- [ ] «Свои правила» в `config.json` (`custom_rules`) — домен из `direct_domains` идёт напрямую

## 7. Подписки: обновление и офлайн

- [ ] `u` — «✓ Обновлено: …», пинги у оставшихся серверов сохранились
- [ ] Отключи сеть (или неверный хост в `state.json`) → `u` — «подписка не отвечает … — работаю на сохранённой копии», серверы на месте, у группы «⚠ не обновилась»
- [ ] Подключение к серверу из сохранённой копии работает
- [ ] Истёкшая подписка — дата красным «истекла …»
- [ ] Автообновление: поставь в настройках 1 ч, подожди (или переведи время) при открытом TUI — обновилась сама
- [ ] `harley update --due` из cron

## 8. Командная строка

- [ ] `harley add '<ключ>'` — импорт + автоподключение, вывод «✓ Подключено: …»
- [ ] `harley add --no-connect '<подписка>'`
- [ ] `harley list`, `harley ping`, `harley connect 2`, `harley connect <часть имени>`
- [ ] `harley status` (код 0) / после `harley disconnect` — «Не подключено» (код 3)
- [ ] Выход из TUI (q) — VPN остаётся подключённым, `harley status` это подтверждает; повторный `harley` видит подключение

## 9. OpenRC

- [ ] Настроил всё от root (`sudo harley`), подключился хотя бы раз
- [ ] `rc-update add harley default`, `rc-service harley start` — «Подключение harley … [ ok ]»
- [ ] `rc-service harley status` — «подключено»
- [ ] Перезагрузка — после загрузки VPN поднят к последнему серверу (`harley status`)
- [ ] Перезагрузка без сети к панели — подключение всё равно поднимается (на сохранённой копии)
- [ ] `rc-service harley stop` — отключено, маршруты убраны
